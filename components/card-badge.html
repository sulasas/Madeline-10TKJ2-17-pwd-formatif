Proyek Saya

Catatan terbaru saya yaitu kegiatan membuat tampilan yang simpel.

Proyek ini adalah halaman web sederhana yang saya buat untuk melatih dasar HTML dan CSS. Saya memulainya dengan merancang tata letak di kertas, lalu menerjemahkannya ke dalam kode.

Untuk membuatnya, saya memakai Visual Studio Code sebagai editor dan browser untuk melihat hasilnya secara langsung. Bahasa yang dipakai adalah HTML untuk struktur dan CSS untuk tampilan.

Kendala yang paling sering saya temui adalah tampilan yang tidak sesuai harapan, seperti jarak antar elemen yang berantakan dan posisi label yang melompat. Saya sempat bingung mencari penyebabnya karena kodenya terlihat benar.

Untuk menyelesaikannya, saya memakai fitur Inspect Element di browser untuk melihat ukuran dan posisi tiap elemen. Dari situ saya tahu bagian mana yang perlu diperbaiki, lalu mencobanya sedikit demi sedikit.

Dari proyek ini saya belajar bahwa box model dan position sangat menentukan tampilan sebuah halaman. Saya juga belajar bahwa menulis kode yang rapi dan memberi nama class yang jelas memudahkan perbaikan.

Ke depannya, saya ingin mengembangkan proyek ini agar tampil baik di layar ponsel dan menambahkan lebih banyak bagian. Saya juga ingin mencoba fitur CSS lain supaya tampilannya lebih menarik.
